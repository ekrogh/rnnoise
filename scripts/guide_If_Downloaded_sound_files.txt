Dataset priority

Yes—Medley-solos-DB is a strong choice for “clean” guitar targets: solo stems reduce accompaniment bleed, which fits RNNoise’s “keep guitar, suppress rest” objective.
Also consider NSynth guitar (single notes) to broaden pitch/dynamics coverage. You can mix both; solos for realism, NSynth for coverage.
Getting it into data/guitar_clean

Easiest: add the Medley-solos-DB direct download link to urls_guitar.txt (open the Zenodo record in a browser and copy the “Download” link). Then run:
s[fetch_real_data.ps1](http://_vscodecontentref_/1) -GuitarUrls [urls_guitar.txt](http://_vscodecontentref_/2) -GuitarOut data/guitar_clean -UseParallel -ParallelJobs 8 -FfmpegThreadsPerJob 1
The fetcher already:
Downloads URLs
Extracts .zip and .tar.gz/.tgz (needs tar)
Converts any audio it finds (wav/flac/mp3/ogg/m4a/aiff) to 48 kHz mono WAV into guitar_clean
If you download archives manually:
Put them in a folder, extract with 7‑Zip or tar (for .tar.gz/.tgz), then either:
Drop the resulting audio files directly under guitar_clean (the pipeline will still resample during concat), or
Run fetch_real_data.ps1 pointing -GuitarOut to that folder to normalize them to 48 kHz mono WAV.
About “.gz”

If it’s .tar.gz/.tgz: supported—script extracts via tar.
If it’s a single-file .gz (e.g., file.wav.gz): extract first (7‑Zip/WSL gunzip), then the WAVs can be used as-is or passed through the fetcher for normalization.
